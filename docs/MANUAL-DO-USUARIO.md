# Manual do usuário — CELC Financeiro

## Para que serve

O CELC Financeiro ajuda a direção a acompanhar o dinheiro que entra e sai do colégio, além das contas que ainda precisam ser pagas ou recebidas.

## Visão geral

Ao abrir o sistema, a tela de acesso é exibida sem dados financeiros. Entre com o usuário `admin` e a senha inicial `admin123`; em seguida, altere essa senha em **Configurações**. Após a autenticação, o painel mostra o saldo disponível, as entradas, as despesas e o resultado do mês.

## Rotina de uso

1. Registre as entradas recebidas, como mensalidades e eventos.
2. Registre as despesas do dia, como materiais, serviços e pagamentos.
3. Cadastre despesas mensais como recorrentes.
4. Consulte as contas pendentes na área de atenção.
5. Faça backup regularmente antes de atualizações.

## Segurança dos dados

Os dados financeiros ficam separados dos arquivos do programa. Atualizar o sistema não remove os lançamentos. O sistema também mantém cópias de segurança para recuperação quando necessário.
