# Guia rápido — CELC Financeiro

| O que deseja fazer | Onde acessar |
|---|---|
| Ver saldo e resultado do mês | Visão geral |
| Registrar uma receita | Entradas → Novo lançamento |
| Registrar um gasto | Despesas → Novo lançamento |
| Consultar vencimentos | Contas a pagar |
| Ver relatórios | Relatórios |
| Fazer cópia de segurança | Configurações → Backup |

Use o botão **Novo lançamento** para registrar rapidamente uma entrada ou despesa. Confirme sempre a data, categoria e valor antes de salvar.
